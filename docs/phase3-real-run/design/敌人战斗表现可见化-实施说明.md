# 敌人战斗表现可见化 · 实施说明

把敌人的攻击表现从"只写日志/tag"变成 PIE 里**肉眼可见**：前摇变色、命中窗口显形、被击闪白、自爆爆球、死亡变灰。给执行者的一次性改动清单。

## 上下文（改之前需要知道的事实）

- 表现层接口已就位并已接线：`enemy_combat` / `enemy_health` / `enemy_death_events` 会在相位切换时调用 `presentation.telegraph / showHitbox / impact / explosion / projectileFx / block / death`，且 `presentation` 已由 `behavior_orchestrator` 注入 `{ worldAdapter }`。**这部分不用动。**
- 问题在实现：`enemy_presentation_runtime.ts.tmpl` 里每个方法目前只有 `setActorTag + log`；`world_adapter.ts.tmpl:189` 的 `cameraImpulse` 也是空 log。没有任何代码/场景消费这些 tag，所以 PIE 里看不到任何东西。
- 表现方法能拿到攻击参数：`telegraph/showHitbox/explosion` 收到的 `params` 里含 `windup_seconds / active_seconds / hitbox_radius / explosion_radius / attack_range`（由 combat 合并 `runtime_params` 后传入）。
- `world_adapter` 已有 `bindTimer(seconds, cb)`，可用于"变色后恢复""临时体到期销毁"。
- 可直接照抄的 UE 写法：`behavior_orchestrator.ts.tmpl:28`（`makeMaterial`：动态材质 + `SetVectorParameterValue('Color', ...)`）、`:29`（`makeWorldMesh`：`StaticMeshComponent` + `/Engine/BasicShapes/*`）、`aid_camera_setup.ts.tmpl:21`（真相机震动）。

## 本次要改的文件

| 文件 | 改什么 |
|---|---|
| `templates/typescript/world_adapter.ts.tmpl` | 新增 3 个可见原语方法；把 `cameraImpulse` 从空 log 改成真震动 |
| `templates/typescript/enemy_presentation_runtime.ts.tmpl` | 每个方法在现有 `setActorTag+log` 基础上，调用新原语产生可见效果 |

## 改动 1：`world_adapter` 新增可见原语

在 `AutoUEWorldAdapter` 类里加下面三个方法（`UE = this.context.UE`）：

```ts
// flashActorColor: 给 actor 的网格套动态材质并变色，seconds 后恢复
// 参考 behavior_orchestrator.ts.tmpl:28 makeMaterial 的 API
flashActorColor(actor, color, seconds)   // color = {r,g,b}
// spawnTempShape: 生成一个 NoCollision 的球/盒占位体（显示范围/命中），seconds 后 destroy
// 参考 behavior_orchestrator.ts.tmpl:29 makeWorldMesh；半径→scale：BasicShapes 半径50@scale1，scale = radius/50
spawnTempShape(center, radius, color, seconds, shape?)   // shape 默认 'Sphere'
// cameraImpulse: 真震动（现为空 log）。对 PlayerCameraManager 施加 shake，或复用 side camera 抖动通道
cameraImpulse(seconds)
```

要点：
- 动态材质：`UE.KismetMaterialLibrary.CreateDynamicMaterialInstance(comp, UE.Material.Load('/Engine/BasicShapes/BasicShapeMaterial'))` → `mat.SetVectorParameterValue('Color', new UE.LinearColor(r,g,b,1))` → `comp.SetMaterial(0, mat)`。恢复：先缓存原材质（或改回默认色），到期用 `bindTimer` 复原；`flashActorColor` 要能重入（记录到期时间，避免颜色卡住）。
- 临时体：`new UE.StaticMeshComponent(owner, name)` → `SetStaticMesh(UE.StaticMesh.Load('/Engine/BasicShapes/Sphere'))` → `SetWorldScale3D` → `SetCollisionEnabled(UE.ECollisionEnabled.NoCollision)` → `RegisterComponent()` → `K2_SetWorldLocation(center,...)`；到期 `bindTimer` 里 `DestroyComponent()`。
- 全部包 `try/catch`，失败只 `log` 不抛（和现有 world_adapter 风格一致）。

## 改动 2：`enemy_presentation_runtime` 各方法接原语

保留现有 `setActorTag + log`，在其后加可见调用（`wa = this.context.worldAdapter`）：

| 方法 | 加的可见效果 |
|---|---|
| `telegraph` | `wa.flashActorColor(enemy.actor, 红, windup_seconds)`；可选 `wa.spawnTempShape(enemy 前方, attack_range, 红半透, windup_seconds)` |
| `showHitbox` | `wa.spawnTempShape(命中中心, hitbox_radius, 黄, active_seconds)` |
| `impact` | `wa.flashActorColor(target, 白, 0.1)` + `wa.cameraImpulse(0.08)` |
| `projectileFx` | `wa.flashActorColor(projectile, 亮青, 0.15)` 或 `spawnTempShape(枪口, 30, 亮青, 0.1)` |
| `explosion` | `wa.spawnTempShape(enemy 位置, explosion_radius, 橙, 0.3)` + `wa.cameraImpulse(0.16)` |
| `block` | `wa.flashActorColor(enemy.actor, 蓝, 0.2)` |
| `death` | `wa.flashActorColor(enemy.actor, 灰, 0.4)`（可选缩小） |

⚠️ `death` 只做视觉，**不要在这里 destroy `enemy.actor`**——销毁由 registry / encounter / reset 流程负责，重复销毁会崩。

## 验收

1. 生成敌人 demo → 部署到 UE → PIE：肉眼可见敌人攻击前变红、命中窗口出现球、玩家被击白闪、自爆橙球、死亡变灰。
2. 把某敌人 `windup_seconds` 从 0.3 改 1.5 → 重生成跑 PIE，红色前摇明显变长（用来证明改动被反映）。
3. 现有日志链 `EnemyAttackTelegraph → EnemyAttackActive → EnemyAttackResolved hit=1/0` 保持不变。
